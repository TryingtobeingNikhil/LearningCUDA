# Prompts

Paste each one into a new chat (Claude, ChatGPT, anything).

| File | Use it for |
|------|-----------|
| [THEORY_PROMPT.md](THEORY_PROMPT.md) | learn the day's topic (type `T05`, `next`, ...) |
| [PRACTICE_PROMPT.md](PRACTICE_PROMPT.md) | get problems on the same topic and have your code reviewed |
| [DIAGRAM_PROMPT.md](DIAGRAM_PROMPT.md) | hand-drawn diagram for the day |
| [POST_PROMPT.md](POST_PROMPT.md) | casual X post for the day |

Daily flow: theory `T05` → practice `T05` → code in `dayXX/` → diagram → post → push.
